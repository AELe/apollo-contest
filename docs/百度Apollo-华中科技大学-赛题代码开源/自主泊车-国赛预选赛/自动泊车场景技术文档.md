


## 第二部分：赛题解题思路文档

### 一、场景回放与赛题分析
**核心需求**：

1. 主车进入泊车场景后，需根据当前车位状况，搜索并驶向距离停车场入口最近的可用泊车位（本实现以路由终点/停车场入口附近为检索核心区域）。
2. 必须在90秒内完成车位识别与泊车入位（规划侧通过启发式暖启动与优化器迭代上限控制确保时效）。
3. 停车时不得压线，须完全停入泊位内（角点与多边形包含判定，提供边界容忍度控制，压线不判定完成）。

**评判标准**：

| 情况                       | 结果   |
| -------------------------- | ------ |
| 90秒内未成功找到并停入车位 | 0分    |
| 停车位置压线               | 扣20分 |

**技术难点**：

- 可用车位搜索与占用判定。
- 开放空间ROI构建与边界扩展。
- 停车完成与压线约束。

**解决思路（本次实现）**：

1. 可用停车位搜索算法：以路由终点（停车场入口）为中心，在一定范围内检索停车位，过滤占用车位（静态/低速障碍物覆盖与多边形重叠判定），从剩余可用车位中选择距离最近者。
2. 开放空间边界扩展算法：在原始车位四角基础上，按“沿道路方向”和“垂直道路方向（深度）”计算候选扩展区域，逐块检测是否无障碍后合并，生成更宽裕的可行驶边界。
3. 车辆停稳判定：对速度/角速度/加速度/方向盘回正进行门限判定；叠加连续帧稳定性检查；再以四角点与车位多边形包含关系（含边界容忍度）最终确认，不满足则不判定完成（避免压线扣分）。
4. 开放空间路径/轨迹调参：针对路径分段/换挡与轨迹优化两个层面分别调参（搜索范围、偏航搜索窗口、分段IoU阈值、优化权重、速度/加速度上限、迭代上限等），在保证安全的前提下提升时效与成功率。

```cpp
// 摘要：从候选车位中过滤占用车位（多边形重叠/中心点包含），选择距离主车最近的可用车位
std::string BestParkingSpaceScenario::SelectBestAvailableParkingSpot(
    const std::vector<ParkingSpaceInfoConstPtr>& available_spots,
    const Frame& frame) {
    // 如果当前没有可用的停车位，则直接返回空字符串
    if (available_spots.empty()) return "";

    // 获取当前车辆的状态信息（位置、速度、航向等）
    const auto& vehicle_state = frame.vehicle_state();
    // 将车辆当前位置的x、y坐标转换为二维向量，便于后续距离计算
    Vec2d vehicle_pos(vehicle_state.x(), vehicle_state.y());

    // 初始化最小距离为最大可能值，用于后续比较寻找最近车位
    double min_distance = std::numeric_limits<double>::max();
    // 存储最终选择的最佳停车位ID
    std::string best_spot_id;

    // 遍历所有可用的停车位信息
    for (const auto& spot : available_spots) {
        // 获取该停车位的多边形边界点（通常为矩形，4个角点）
        const auto& pts = spot->polygon().points();
        
        // 如果该停车位的边界点少于4个（非标准矩形或数据异常），则跳过该车位
        if (pts.size() < 4) continue;

        // 计算该停车位的几何中心点（四个角点的平均值）
        // 假设停车位为四边形，取四个顶点的中心作为代表位置
        Vec2d center = (pts[0] + pts[1] + pts[2] + pts[3]) / 4.0;

        // 计算当前车辆位置到该停车位中心点的欧几里得距离
        double d = vehicle_pos.DistanceTo(center);

        // 如果当前车位距离比已记录的最小距离更近，则更新最佳车位
        if (d < min_distance) {
            min_distance = d;  // 更新最小距离
            best_spot_id = spot->parking_space().id().id();  // 更新最佳车位ID
        }
    }

    // 返回距离最近的可用停车位的ID（若无有效车位则返回空字符串）
    return best_spot_id;
}
```

```cpp
// 核心片段：整体扩展候选 -> 安全检测 -> 分区扩展回退
// 计算停车位的原始长度（沿道路方向，即车辆驶入方向）
double parking_length = left_top.DistanceTo(right_top);  // 左上角到右上角的距离 → 车位沿道路方向的长度
// 计算停车位的原始宽度（垂直于道路方向，即车辆侧向进入深度）
double parking_width  = left_top.DistanceTo(left_down);   // 左上角到左下角的距离 → 车位垂直于道路的深度

// 定义扩展系数：为确保车辆能安全、无碰撞地停入，需在原始车位基础上向外扩张一个“安全缓冲区”
const double lateral_expansion = parking_length * 0.9;  // 沿道路方向（长度方向）的扩展量：90%车位长度 → 为前后留出足够空间，防止前后车干扰
const double depth_expansion   = parking_width  * 0.6;  // 垂直于道路方向（宽度方向）的扩展量：60%车位深度 → 为左右侧留出避障空间，防止蹭墙或障碍物

// 计算车位长度方向的单位向量（从左上指向右上，即车辆驶入方向）
Vec2d length_direction = right_top - left_top; 
length_direction.Normalize();  // 归一化，得到单位方向向量，用于后续方向扩展

// 计算车位宽度方向的单位向量（从左上指向左下，即车辆侧向进入方向）
Vec2d width_direction  = left_down - left_top; 
width_direction.Normalize();   // 归一化，得到垂直于行驶方向的单位向量

// 根据扩展量，计算“扩展后”的四角点坐标（形成一个更大的安全区域，用于检测是否可停）
Vec2d cand_lt = left_top  - length_direction * lateral_expansion;  // 扩展后的左上角：向后（远离道路）偏移
Vec2d cand_rt = right_top + length_direction * lateral_expansion;  // 扩展后的右上角：向前（朝向道路）偏移
Vec2d cand_ld = left_down - length_direction * lateral_expansion + width_direction * depth_expansion;  // 扩展后的左下角：向后+向外（远离车身）偏移
Vec2d cand_rd = right_down + length_direction * lateral_expansion + width_direction * depth_expansion; // 扩展后的右下角：向前+向外偏移

// 构建扩展后的四边形区域（安全检测区域），按顺时针顺序：左上 → 右上 → 右下 → 左下
std::vector<Vec2d> full{cand_lt, cand_rt, cand_rd, cand_ld};

// 检查该扩展后的区域是否完全无障碍物（如其他车辆、路沿、行人、静态障碍等）
// IsAreaFreeOfObstaclesSafe 是一个关键安全函数，通常基于激光雷达、摄像头或高精地图进行区域碰撞检测
if (IsAreaFreeOfObstaclesSafe(full, frame)) {
    // 若检测通过，说明该车位不仅原始可用，且周围有足够的安全缓冲空间
    *expanded_left_top  = cand_lt;
    *expanded_right_top = cand_rt;
    *expanded_left_down = cand_ld;
    *expanded_right_down = cand_rd;

    // 返回 true 表示该车位满足安全扩展条件，可作为候选停车目标
    return true;
}

// 若未通过安全检测，函数默认返回 false（调用方需继续寻找其他车位）
// 否则逐块（左/右/深度/组合）检测，能扩则扩，最终合成。
```

**可用车位选择（最近原则）**
- 路径`scenarios/best_parking_space/best_parking_space.cc`
- 函数`SelectBestAvailableParkingSpot`

```cpp
/**
 * @brief 从可用停车位列表中选择距离车辆当前位置最近的停车位作为最佳停车目标。
 
 * 本函数的核心逻辑是：遍历所有可用停车位，计算每个停车位中心点到当前车辆位置的欧氏距离，
 * 并选择距离最小的停车位作为推荐目标。该策略适用于“就近停车”场景，如城市道路边停车、
 * 停车场入口引导等。不考虑停车位朝向、是否被占用（已由上游过滤）、障碍物避让等复杂因素，

 * 注意：假设所有传入的停车位均为“有效且可停”状态（由上游模块过滤），仅做距离筛选。
 * 多边形点数不足4个的停车位将被跳过，避免计算错误。

 * @param available_spots 所有当前可用的停车位信息指针列表（由感知/地图模块提供）
 * @param frame 当前帧的全局状态，包含车辆位置、速度、航向等信息
 * @return std::string 返回最佳停车位的唯一ID（string类型），若无可用停车位则返回空字符串
 */
std::string BestParkingSpaceScenario::SelectBestAvailableParkingSpot(
    const std::vector<ParkingSpaceInfoConstPtr>& available_spots,
    const Frame& frame) {
    
    // ----------------------- 【边界条件检查】 -----------------------
    // 如果没有可用停车位，直接返回空字符串并记录日志，避免后续无效计算
    if (available_spots.empty()) {
        AINFO << "没有可用的停车位：感知模块未检测到任何可停车区域，可能处于无停车环境或感知失效。";
        return "";
    }
    
    // ----------------------- 【获取车辆当前状态】 -----------------------
    // 获取当前车辆的运动状态（位置、速度、航向等）
    const auto& vehicle_state = frame.vehicle_state();
    
    // 将车辆的二维坐标（x, y）转换为 Vec2d 类型，便于进行几何距离计算
    // Vec2d 是 Apollo 中用于二维向量运算的轻量级类，支持点积、距离计算等操作
    Vec2d vehicle_pos(vehicle_state.x(), vehicle_state.y());
    
    // 初始化最小距离为最大可能值，确保第一个有效停车位的距离会被采纳
    double min_distance = std::numeric_limits<double>::max();
    
    // 初始化最佳停车位ID为空字符串，用于记录最终选择结果
    std::string best_spot_id;
    
    AINFO << "开始选择最佳停车位，候选数量: " << available_spots.size()
          << "，当前车辆位置: (" << vehicle_pos.x() << ", " << vehicle_pos.y() << ")";

    // ----------------------- 【主循环：遍历所有候选停车位】 -----------------------
    // 对每一个可用停车位进行处理，计算其中心点与车辆的距离
    for (const auto& spot : available_spots) {
        
        // 获取该停车位的多边形边界点（通常为矩形，4个角点）
        const auto& points = spot->polygon().points();
        
        // 【安全检查】确保多边形至少包含4个点（矩形最小构成）
        // 若点数不足，说明数据异常或几何定义错误，跳过该停车位以避免计算错误
        if (points.size() < 4) {
            AWARN << "停车位 " << spot->parking_space().id().id() 
                  << " 的多边形点数不足（仅 " << points.size() << " 个点），跳过该无效区域。"
                  << " 可能原因：地图数据错误、传感器误检、或非标准停车位形状。";
            continue;  // 跳过此无效停车位，继续下一个
        }
        
        // ----------------------- 【计算停车位中心点】 -----------------------
        // 使用四个角点的算术平均值作为停车位中心点（适用于矩形或近似矩形）
        // 点坐标相加后除以4，得到几何中心（质心）
        // 注意：此方法在非矩形四边形中可能不精确，但工程上对停车场场景足够鲁棒
        Vec2d center_point = (points[0] + points[1] + points[2] + points[3]) / 4.0;
        
        // ----------------------- 【计算车辆到中心点的欧氏距离】 -----------------------
        // 使用 Vec2d::DistanceTo() 方法计算两点间直线距离（单位：米）
        double distance = vehicle_pos.DistanceTo(center_point);
        
        // ----------------------- 【调试日志：输出每个候选点的距离】 -----------------------
        // 记录每个候选停车位的ID及其与车辆的距离，便于调试和性能分析
        AINFO << "停车位 ID: " << spot->parking_space().id().id() 
              << " | 中心坐标: (" << center_point.x() << ", " << center_point.y() << ") "
              << "| 距离车辆: " << std::fixed << std::setprecision(2) << distance << "m";
        
        // ----------------------- 【更新最佳选择】 -----------------------
        // 如果当前停车位距离更近，则更新最小距离和最佳ID
        // 此处采用贪心策略：仅选最近者，不考虑其他因素（如朝向、入口方向、坡度等）
        if (distance < min_distance) {
            min_distance = distance;          // 更新最小距离
            best_spot_id = spot->parking_space().id().id();  // 更新最佳停车位ID
        }
    }
    
    // ----------------------- 【结果输出与返回】 -----------------------
    // 输出最终选定的最佳停车位信息，便于日志追踪和系统调试
    if (!best_spot_id.empty()) {
        AINFO << "✅ 选择最佳停车位成功: " << best_spot_id 
              << " | 最短距离: " << std::fixed << std::setprecision(2) << min_distance << "m";
    } else {
        AINFO << "❌ 所有候选停车位均无效（无有效几何数据），未选择任何停车位。";
    }
    
    // 返回最终选定的停车位ID，若无有效候选则返回空字符串
    return best_spot_id;
}
```

```cpp
    // 方式1: 检查Frame中的障碍物 (当前方式)
    // 获取当前帧中由感知模块提供的所有障碍物列表
    const auto& frame_obstacles = frame.obstacles();
    // 输出当前帧中感知到的障碍物总数
    AINFO << "方式1 - Frame中障碍物数量: " << frame_obstacles.size();

    // 方式2: 直接从local_view获取预测障碍物
    // 初始化预测障碍物计数器
    int prediction_obstacle_count = 0;
    // 检查Frame的local_view中是否包含预测障碍物数据（来自预测模块）
    if (frame.local_view().prediction_obstacles) {
        // 获取预测障碍物的指针
        const auto& prediction_obs = frame.local_view().prediction_obstacles;
        // 获取预测障碍物的总数（来自PredictionObstacleList）
        prediction_obstacle_count = prediction_obs->prediction_obstacle_size();
        // 输出预测障碍物数量和其时间戳（用于调试时序一致性）
        AINFO << "方式2 - 预测障碍物数量: " << prediction_obstacle_count;
        AINFO << "预测数据时间戳: " << prediction_obs->header().timestamp_sec();

        // 重新声明 parking_polygon（与上方重复，但保留原代码结构）
        // 注意：此变量已在函数开头定义，此处再次声明为局部作用域变量，覆盖外层
        const auto& parking_polygon = parking_space->polygon();
        // 重新声明 occupation_threshold（重复定义，保留原样）
        const double occupation_threshold = 0.2;
        // 重新声明 parking_area（重复定义，保留原样）
        const double parking_area = parking_polygon.area();

        // 遍历每一个预测障碍物
        for (int i = 0; i < prediction_obs->prediction_obstacle_size(); ++i) {
            // 获取第i个预测障碍物对象
            const auto& pred_obs = prediction_obs->prediction_obstacle(i);
            // 获取该预测障碍物对应的原始感知障碍物（即感知模块输出的原始数据）
            const auto& perception_obs = pred_obs.perception_obstacle();

            // 输出当前预测障碍物的ID、类型、位置和速度（用于调试）
            AINFO << "  预测障碍物[" << i << "] ID: " << perception_obs.id() << ", 类型: " << perception_obs.type()
                  << ", 位置: (" << perception_obs.position().x() << ", " << perception_obs.position().y() << ")"
                  << ", 速度: " << perception_obs.velocity().x() << "," << perception_obs.velocity().y();

            // 计算该障碍物的当前速度大小（欧氏速度）
            double obstacle_speed = std::sqrt(
                    perception_obs.velocity().x() * perception_obs.velocity().x()
                    + perception_obs.velocity().y() * perception_obs.velocity().y());

            // 判断是否为静态或低速障碍物（可能长期占用停车位）
            // 包括：未知不可移动物体、自行车、车辆，或速度低于0.5m/s的障碍物
            if (perception_obs.type() == apollo::perception::PerceptionObstacle::UNKNOWN_UNMOVABLE
                || perception_obs.type() == apollo::perception::PerceptionObstacle::BICYCLE
                || perception_obs.type() == apollo::perception::PerceptionObstacle::VEHICLE
                || obstacle_speed < 0.5) {  // 静态或低速障碍物

                // 创建障碍物中心点（基于感知位置）
                apollo::common::math::Vec2d obstacle_center(
                        perception_obs.position().x(), perception_obs.position().y());

                // 检查障碍物中心点是否落在停车位多边形内部（快速粗略判断）
                if (parking_polygon.IsPointIn(obstacle_center)) {
                    AINFO << "停车位 " << parking_space->parking_space().id().id() << " 被障碍物 "
                          << perception_obs.id() << " 占用（通过预测数据检测）";
                    // 若中心点在内，立即返回true，判定为占用
                    return true;
                }

                // 进一步检查：如果障碍物有完整的多边形点（非仅中心点），则构建完整多边形进行重叠检测
                if (perception_obs.polygon_point_size() > 0) {
                    // 创建一个用于存储障碍物多边形点的向量
                    std::vector<apollo::common::math::Vec2d> obstacle_points;
                    // 遍历障碍物的所有多边形顶点，转换为Vec2d格式
                    for (const auto& point : perception_obs.polygon_point()) {
                        obstacle_points.emplace_back(point.x(), point.y());
                    }

                    // 确保至少有3个点才能构成有效多边形（三角形及以上）
                    if (obstacle_points.size() >= 3) {
                        // 使用障碍物点构建Polygon2d对象，用于精确几何重叠检测
                        apollo::common::math::Polygon2d obstacle_polygon(obstacle_points);
                        // 检查障碍物多边形与停车位多边形是否有重叠区域
                        if (parking_polygon.HasOverlap(obstacle_polygon)) {
                            // 简化计算：假设重叠面积等于停车位面积（保守估计，实际应为交集面积）
                            double overlap_area = parking_polygon.area();  // 简化计算
                            // 计算重叠比例（重叠面积 / 停车位总面积），上限为1.0
                            double overlap_ratio = std::min(overlap_area / parking_area, 1.0);

                            // 如果重叠比例超过阈值，则判定为占用
                            if (overlap_ratio > occupation_threshold) {
                                AINFO << "停车位 " << parking_space->parking_space().id().id() << " 被障碍物 "
                                      << perception_obs.id() << " 占用（重叠比例: " << (overlap_ratio * 100) << "%）";
                                // 立即返回true，停止检测
                                return true;
                            }
                        }
                    }
                }
            }
        }
    } else {
        // 如果prediction_obstacles指针为空，记录警告日志
        AWARN << "方式2 - prediction_obstacles为空！";
    }

    // 方式3: 检查ReferenceLineInfo中的障碍物决策（规划模块的决策结果，非几何数据）
    // 检查Frame中是否存在参考线信息（通常至少有一条）
    if (!frame.reference_line_info().empty()) {
        // 获取第一条参考线信息（通常主路径）
        const auto& ref_line_info = frame.reference_line_info().front();
        // 获取该参考线上的路径决策对象（包含障碍物决策状态）
        const auto& path_decision = ref_line_info.path_decision();

        // 输出路径决策中包含的障碍物数量
        AINFO << "方式3 - 路径决策中的障碍物数量: " << path_decision.obstacles().Items().size();

        // 遍历路径决策中的所有障碍物（这些是规划模块标记的“需要避让”或“被阻塞”的障碍物）
        for (const auto* obstacle : path_decision.obstacles().Items()) {
            // 输出每个障碍物的ID、是否为静态、是否为虚拟障碍物（用于调试）
            AINFO << "  路径决策障碍物 ID: " << obstacle->Id() << ", 静态: " << (obstacle->IsStatic() ? "是" : "否")
                  << ", 虚拟: " << (obstacle->IsVirtual() ? "是" : "否");
        }
    }

    // 方式4: 通过Cyber直接获取障碍物数据 (如果可能的话)
    AINFO << "=== 障碍物数据获取完毕 ===";

    // 如果Frame中没有感知障碍物，但预测障碍物有数据，说明可能存在数据同步或过滤问题
    if (frame_obstacles.size() == 0 && prediction_obstacle_count > 0) {
        // 输出警告，提示系统可能存在数据不一致
        AWARN << "发现数据转换问题: Frame中无障碍物但预测中有 " << prediction_obstacle_count << " 个障碍物";
        AWARN << "可能原因: 1) 障碍物被过滤 2) 数据时序问题 3) Frame构建问题";
    }

    // 遍历Frame中的所有感知障碍物（方式1的主检测逻辑）
    for (const auto& obstacle : frame.obstacles()) {
        // 检查障碍物是否为静态（如停靠车辆、锥桶）或速度低于阈值（0.5m/s）
        // 低速障碍物也被视为可能占用停车位（如缓慢移动的车辆）
        if (obstacle->IsStatic() || obstacle->speed() < 0.5) { // 速度小于0.5m/s认为静止
            
            // 获取障碍物的感知包围盒（Box2d），用于获取其边界角点
            const auto& obstacle_box = obstacle->PerceptionBoundingBox();
            
            // 获取包围盒的四个角点（按顺时针或逆时针顺序）
            const auto& box_corners = obstacle_box.GetAllCorners();
            // 如果角点数量不足4个（理论上应为4个），则跳过该障碍物（避免非法构造）
            if (box_corners.size() < 4) {
                AWARN << "障碍物 " << obstacle->Id() << " 边界框角点数量不足";
                continue;
            }
            
            // 创建一个向量用于存储障碍物的多边形顶点（转换为Vec2d）
            std::vector<Vec2d> obstacle_points;
            // 遍历每个角点，转换为Vec2d并加入向量
            for (const auto& corner : box_corners) {
                obstacle_points.push_back(corner);
            }
            // 使用障碍物角点构建Polygon2d对象，用于精确几何检测
            Polygon2d obstacle_polygon(obstacle_points);
            
            // 检查障碍物多边形与停车位多边形是否有重叠
            if (parking_polygon.HasOverlap(obstacle_polygon)) {
                // 简化计算：使用障碍物包围盒面积作为重叠面积的近似值（非精确交集）
                double obstacle_area = obstacle_box.length() * obstacle_box.width();
                // 计算重叠比例：障碍物面积 / 停车位面积，上限为1.0（避免超过100%）
                double overlap_ratio = std::min(obstacle_area / parking_area, 1.0);
                
                // 输出重叠信息（用于调试）
                AINFO << "停车位 " << parking_space->parking_space().id().id() 
                      << " 与障碍物 " << obstacle->Id() 
                      << " 重叠，重叠比例: " << (overlap_ratio * 100) << "%";
                
                // 如果重叠比例超过阈值（20%），则判定为被占用
                if (overlap_ratio > occupation_threshold) {
                    AINFO << "停车位 " << parking_space->parking_space().id().id() << " 被占用";
                    // 立即返回true，结束函数
                    return true;
                }
            }
        }
    }
    
    // 所有检测方式均未发现占用，输出“未被占用”日志
    AINFO << "停车位 " << parking_space->parking_space().id().id() << " 未被占用";
    // 返回false，表示该停车位当前未被占用
    return false;
}
```

**开放空间边界扩展（沿道路与深度方向）**
- 路径`tasks/open_space_roi_decider/open_space_roi_decider.cc`
- 函数`ExpandParkingSpaceIfFree`

```cpp
/**
 * @brief 检查停车位沿道路方向（前后）和深度方向（远离道路）的周边空间是否空闲，
 *        若空闲则尝试扩展停车位边界，以提供更宽松的泊车区域。
 * 
 * 本函数的目标是：在原始停车位基础上，向外扩展一个“安全缓冲区”，
 * 用于提升泊车成功率扩展策略为：
 *   - 沿道路方向（长度方向）扩展0.9倍车位长度（前方+后方）
 *   - 深度方向（宽度方向）扩展0.6倍车位宽度（远离道路一侧）
 * 扩展优先级：
 *   1. 先尝试完整扩展（前后+深度）
 *   2. 若失败，尝试分区域扩展（左前、右后、深度）
 *   3. 再尝试组合扩展（左前+深度、右后+深度）
 *   4. 最后尝试仅深度扩展
 * 
 * 所有扩展区域均通过 IsAreaFreeOfObstaclesSafe() 检查障碍物，确保安全。
 * 若无任何扩展可行，则返回原始停车位边界。
 * 
 * 注意：本函数不修改原始停车位数据，仅通过指针输出扩展后的候选边界。
 * 
 * @param parking_info 原始停车位的四个角点信息（顺序：左上、右上、右下、左下）
 * @param frame 当前帧状态，包含障碍物、地图、感知等信息，用于检测扩展区域是否空闲
 * @param expanded_left_top 输出：扩展后的左上角点坐标
 * @param expanded_right_top 输出：扩展后的右上角点坐标
 * @param expanded_left_down 输出：扩展后的左下角点坐标
 * @param expanded_right_down 输出：扩展后的右下角点坐标
 * @return bool true = 成功扩展至少一个方向；false = 未扩展，返回原始边界
 */
bool OpenSpaceRoiDecider::ExpandParkingSpaceIfFree(
        const ParkingInfo &parking_info,
        Frame *const frame,
        Vec2d *expanded_left_top,
        Vec2d *expanded_right_top,
        Vec2d *expanded_left_down,
        Vec2d *expanded_right_down) {
    
    // 日志：开始执行扩展检测逻辑
    AINFO << "开始检查停车位沿道路方向和深度方向的周边空间是否可以扩展";

    // 获取原始停车位的四个角点（按顺序：左上、右上、右下、左下）
    const auto &left_top = parking_info.corner_points[0];     // 停车位左上角点
    const auto &right_top = parking_info.corner_points[1];    // 停车位右上角点
    const auto &right_down = parking_info.corner_points[2];   // 停车位右下角点
    const auto &left_down = parking_info.corner_points[3];    // 停车位左下角点

    // 计算停车位的长度（沿道路方向，即左上到右上的距离）
    double parking_length = left_top.DistanceTo(right_top);  // 沿道路方向的长度
    // 计算停车位的宽度（垂直道路方向，即左上到左下的距离）
    double parking_width = left_top.DistanceTo(left_down);   // 垂直道路方向的宽度

    // 设置沿道路方向的扩展距离：0.9倍车位长度（向前和向后各扩展一半）
    const double lateral_expansion = parking_length * 0.9;  // 沿道路方向扩展0.9个车位长度
    // 设置深度方向的扩展距离：0.6倍车位宽度（仅向远离道路方向扩展）
    const double depth_expansion = parking_width * 0.6;     // 深度方向扩展0.6个车位宽度

    // 日志输出原始停车位尺寸
    AINFO << "停车位尺寸 - 长度: " << parking_length << "m, 宽度: " << parking_width << "m";
    // 日志输出沿道路方向扩展距离
    AINFO << "沿道路方向扩展距离: " << lateral_expansion << "m";
    // 日志输出深度方向扩展距离
    AINFO << "深度方向扩展距离: " << depth_expansion << "m";

    // 计算停车位沿道路方向的单位向量（从左上指向右上）
    Vec2d length_direction = right_top - left_top;  // 沿道路方向
    // 将向量归一化，得到单位方向向量，用于后续精确偏移
    length_direction.Normalize();

    // 计算停车位深度方向的单位向量（从左上指向左下，指向远离道路一侧）
    Vec2d width_direction = left_down - left_top;  // 垂直道路方向（向内）
    // 将向量归一化，得到单位方向向量，用于深度扩展
    width_direction.Normalize();

    // 计算完整扩展后的四个候选角点：
    // - 左上角点：原始左上点，沿道路反方向（前方）偏移 lateral_expansion
    Vec2d candidate_left_top = left_top - length_direction * lateral_expansion;
    // - 右上角点：原始右上点，沿道路正方向（后方）偏移 lateral_expansion
    Vec2d candidate_right_top = right_top + length_direction * lateral_expansion;
    // - 左下角点：原始左下点，沿道路反方向偏移 lateral_expansion，同时深度方向正向偏移 depth_expansion
    Vec2d candidate_left_down = left_down - length_direction * lateral_expansion + width_direction * depth_expansion;
    // - 右下角点：原始右下点，沿道路正方向偏移 lateral_expansion，同时深度方向正向偏移 depth_expansion
    Vec2d candidate_right_down = right_down + length_direction * lateral_expansion + width_direction * depth_expansion;

    // 日志输出完整扩展候选区域的四个角点坐标（用于调试）
    AINFO << "候选扩展区域（沿道路方向和深度方向）:";
    AINFO << "  candidate_left_top: (" << std::fixed << std::setprecision(2) << candidate_left_top.x() << ", "
          << candidate_left_top.y() << ")";
    AINFO << "  candidate_right_top: (" << std::fixed << std::setprecision(2) << candidate_right_top.x() << ", "
          << candidate_right_top.y() << ")";
    AINFO << "  candidate_left_down: (" << std::fixed << std::setprecision(2) << candidate_left_down.x() << ", "
          << candidate_left_down.y() << ")";
    AINFO << "  candidate_right_down: (" << std::fixed << std::setprecision(2) << candidate_right_down.x() << ", "
          << candidate_right_down.y() << ")";

    // 构建完整扩展区域的多边形点序列（顺时针或逆时针顺序，用于面积和障碍物检测）
    std::vector<Vec2d> full_expansion_points{
            candidate_left_top, candidate_right_top, candidate_right_down, candidate_left_down};
    // 计算完整扩展区域的面积（使用多边形面积公式）
    double full_expansion_area = CalculatePolygonArea(full_expansion_points);
    // 设置最小有效面积阈值，避免退化为线或点
    const double min_area_threshold = 1e-8;  // 最小面积阈值

    // 如果完整扩展区域面积过小（退化），则放弃扩展，直接返回原始边界
    if (full_expansion_area < min_area_threshold) {
        AINFO << "完整扩展区域面积过小: " << full_expansion_area << "，跳过扩展";
        // 输出原始边界，不进行任何扩展
        *expanded_left_top = left_top;
        *expanded_right_top = right_top;
        *expanded_left_down = left_down;
        *expanded_right_down = right_down;
        return false;
    }

    // 检查完整扩展区域是否完全无障碍物（调用安全检测函数）
    if (IsAreaFreeOfObstaclesSafe(full_expansion_points, frame)) {
        AINFO << "整个扩展区域（道路方向+深度方向）空闲，可以完全扩展";
        // 若空闲，则输出完整扩展后的边界作为结果
        *expanded_left_top = candidate_left_top;
        *expanded_right_top = candidate_right_top;
        *expanded_left_down = candidate_left_down;
        *expanded_right_down = candidate_right_down;
        return true;
    } else {
        AINFO << "完整扩展区域存在障碍物，尝试分区域扩展";

        // 初始化最终扩展边界为原始边界，作为默认值
        Vec2d final_left_top = left_top;
        Vec2d final_right_top = right_top;
        Vec2d final_left_down = left_down;
        Vec2d final_right_down = right_down;

        // 标记是否成功进行了任何扩展（用于最终判断）
        bool has_any_expansion = false;

        // ==================== 1. 检查左侧（道路前方）扩展 ====================
        // 计算左侧扩展后的两个新角点：左上和左下均沿道路反方向偏移
        Vec2d left_expanded_left_top = left_top - length_direction * lateral_expansion;
        Vec2d left_expanded_left_down = left_down - length_direction * lateral_expansion;
        // 构建左侧扩展区域的四边形（左上→原始左上→原始左下→扩展左下）
        std::vector<Vec2d> left_expansion_points{left_expanded_left_top, left_top, left_down, left_expanded_left_down};
        // 计算该区域面积
        double left_expansion_area = CalculatePolygonArea(left_expansion_points);

        // 若面积有效且无障碍物，则接受该扩展
        if (left_expansion_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(left_expansion_points, frame)) {
            AINFO << "左侧（道路前方）区域空闲，可以扩展";
            // 更新最终左上和左下边界
            final_left_top = left_expanded_left_top;
            final_left_down = left_expanded_left_down;
            has_any_expansion = true; // 标记已扩展
        }

        // ==================== 2. 检查右侧（道路后方）扩展 ====================
        // 计算右侧扩展后的两个新角点：右上和右下均沿道路正方向偏移
        Vec2d right_expanded_right_top = right_top + length_direction * lateral_expansion;
        Vec2d right_expanded_right_down = right_down + length_direction * lateral_expansion;
        // 构建右侧扩展区域的四边形（原始右上→扩展右上→扩展右下→原始右下）
        std::vector<Vec2d> right_expansion_points{
                right_top, right_expanded_right_top, right_expanded_right_down, right_down};
        // 计算该区域面积
        double right_expansion_area = CalculatePolygonArea(right_expansion_points);

        // 若面积有效且无障碍物，则接受该扩展
        if (right_expansion_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(right_expansion_points, frame)) {
            AINFO << "右侧（道路后方）区域空闲，可以扩展";
            // 更新最终右上和右下边界
            final_right_top = right_expanded_right_top;
            final_right_down = right_expanded_right_down;
            has_any_expansion = true; // 标记已扩展
        }

        // ==================== 3. 检查深度方向扩展（远离道路一侧） ====================
        // 使用当前最终的左下和右下作为基点，向深度方向（远离道路）偏移
        Vec2d depth_expanded_left_down = final_left_down + width_direction * depth_expansion;
        Vec2d depth_expanded_right_down = final_right_down + width_direction * depth_expansion;
        // 构建深度扩展区域：原始左下→原始右下→扩展右下→扩展左下
        std::vector<Vec2d> depth_expansion_points{
                final_left_down, final_right_down, depth_expanded_right_down, depth_expanded_left_down};
        // 计算面积
        double depth_expansion_area = CalculatePolygonArea(depth_expansion_points);

        // 若面积有效且无障碍物，则接受深度扩展
        if (depth_expansion_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(depth_expansion_points, frame)) {
            AINFO << "深度方向（远离道路）区域空闲，可以扩展";
            // 更新最终左下和右下边界
            final_left_down = depth_expanded_left_down;
            final_right_down = depth_expanded_right_down;
            has_any_expansion = true; // 标记已扩展
        }

        // ==================== 4. 尝试组合扩展：左侧 + 深度方向 ====================
        // 若尚未有任何扩展，尝试组合扩展（左前方 + 深度）
        if (!has_any_expansion) {
            // 左侧扩展的左上角点
            Vec2d combo_left_top = left_top - length_direction * lateral_expansion;
            // 组合左下角点：左下点先沿道路反方向偏移，再向深度方向偏移
            Vec2d combo_left_down
                    = left_down - length_direction * lateral_expansion + width_direction * depth_expansion;
            // 构建组合区域：组合左上→原始左上→原始左下→组合左下
            std::vector<Vec2d> combo_left_points{combo_left_top, left_top, left_down, combo_left_down};
            // 计算面积
            double combo_left_area = CalculatePolygonArea(combo_left_points);

            // 若面积有效且无障碍物，则接受此组合扩展
            if (combo_left_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(combo_left_points, frame)) {
                AINFO << "左侧+深度组合区域空闲，可以扩展";
                // 更新最终左上和左下
                final_left_top = combo_left_top;
                final_left_down = combo_left_down;
                has_any_expansion = true; // 标记已扩展
            }
        }

        // ==================== 5. 尝试组合扩展：右侧 + 深度方向 ====================
        // 若尚未有任何扩展，尝试组合扩展（右后方 + 深度）
        if (!has_any_expansion) {
            // 右侧扩展的右上角点
            Vec2d combo_right_top = right_top + length_direction * lateral_expansion;
            // 组合右下角点：右下点先沿道路正方向偏移，再向深度方向偏移
            Vec2d combo_right_down
                    = right_down + length_direction * lateral_expansion + width_direction * depth_expansion;
            // 构建组合区域：原始右上→组合右上→组合右下→原始右下
            std::vector<Vec2d> combo_right_points{right_top, combo_right_top, combo_right_down, right_down};
            // 计算面积
            double combo_right_area = CalculatePolygonArea(combo_right_points);

            // 若面积有效且无障碍物，则接受此组合扩展
            if (combo_right_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(combo_right_points, frame)) {
                AINFO << "右侧+深度组合区域空闲，可以扩展";
                // 更新最终右上和右下
                final_right_top = combo_right_top;
                final_right_down = combo_right_down;
                has_any_expansion = true; // 标记已扩展
            }
        }

        // ==================== 6. 最后尝试：仅深度方向扩展 ====================
        // 若仍无任何扩展，尝试仅向深度方向扩展（不改变前后位置）
        if (!has_any_expansion) {
            // 原始左下和右下点，仅向深度方向偏移
            Vec2d depth_only_left_down = left_down + width_direction * depth_expansion;
            Vec2d depth_only_right_down = right_down + width_direction * depth_expansion;
            // 构建仅深度扩展区域：原始左下→原始右下→扩展右下→扩展左下
            std::vector<Vec2d> depth_only_points{left_down, right_down, depth_only_right_down, depth_only_left_down};
            // 计算面积
            double depth_only_area = CalculatePolygonArea(depth_only_points);

            // 若面积有效且无障碍物，则接受仅深度扩展
            if (depth_only_area >= min_area_threshold && IsAreaFreeOfObstaclesSafe(depth_only_points, frame)) {
                AINFO << "仅深度方向区域空闲，可以扩展";
                // 更新最终左下和右下
                final_left_down = depth_only_left_down;
                final_right_down = depth_only_right_down;
                has_any_expansion = true; // 标记已扩展
            }
        }

        // 将最终选定的扩展边界赋值给输出参数
        *expanded_left_top = final_left_top;
        *expanded_right_top = final_right_top;
        *expanded_left_down = final_left_down;
        *expanded_right_down = final_right_down;

        // 根据是否发生任何扩展，输出最终结果
        if (has_any_expansion) {
            AINFO << "成功进行部分区域扩展";
            // 输出扩展后各角点坐标（用于调试）
            AINFO << "扩展后 left_top: (" << std::fixed << std::setprecision(2) << final_left_top.x() << ", "
                  << final_left_top.y() << ")";
            AINFO << "扩展后 right_top: (" << std::fixed << std::setprecision(2) << final_right_top.x() << ", "
                  << final_right_top.y() << ")";
            AINFO << "扩展后 left_down: (" << std::fixed << std::setprecision(2) << final_left_down.x() << ", "
                  << final_left_down.y() << ")";
            AINFO << "扩展后 right_down: (" << std::fixed << std::setprecision(2) << final_right_down.x() << ", "
                  << final_right_down.y() << ")";
            return true; // 成功扩展至少一个方向
        } else {
            AINFO << "无法进行任何扩展，使用原始停车位边界";
            return false; // 未扩展，返回原始边界
        }
    }
}
```

**停车完成与压线判定（连续帧稳定 + 多边形包含）**

```cpp
/**
 * @brief 检查车辆是否已完成泊车：判断车辆是否静止且完全位于目标停车位内。
 * 
 * 本函数是“最佳停车位场景”中的关键状态判断函数，用于确认泊车动作是否成功结束。
 * 检查分为两个阶段：
 *   1. 车辆连续稳定静止（速度、加速度、方向盘、位置、朝向均在容差内）≥30帧（约1秒）
 *   2. 车辆的四个角点全部位于目标停车位多边形内（允许10cm边界容忍）
 * 
 * 若两阶段均通过，则判定“停车完成”，返回 true，并重置内部状态。
 * 若任一阶段失败，则返回 false，并重置状态以支持下一次停车检测。
 * 

 * @param frame 当前帧的全局状态，包含车辆状态、地图、障碍物等信息
 * @return bool true = 停车完成；false = 停车未完成，继续等待或重试
 */
bool StageBestParking::CheckParkingComplete(const Frame& frame) {
    
    // 获取当前车辆状态（来自运动学模块）
    const auto& vehicle_state = frame.vehicle_state();
    
    // 获取当前场景上下文（转换为 BestParkingSpaceContext 类型）
    auto scenario_context = GetContextAs<BestParkingSpaceContext>();

    // ----------------------- 【1. 获取车辆当前状态参数】 -----------------------
    // 获取车辆线性速度（m/s）
    double vehicle_speed = vehicle_state.linear_velocity();
    // 获取车辆角速度（rad/s）
    double angular_velocity = vehicle_state.angular_velocity();
    // 获取车辆线性加速度（m/s²）
    double linear_acceleration = vehicle_state.linear_acceleration();
    // 获取方向盘转角百分比（0~100%，正负表示左右转向）
    double steering_percentage = vehicle_state.steering_percentage();

    // 日志输出当前车辆状态详情，用于调试与分析
    AINFO << "车辆状态详情:";
    AINFO << "  位置: (" << std::fixed << std::setprecision(4) << vehicle_state.x() << ", " << vehicle_state.y() << ", "
          << vehicle_state.z() << ")";  // x, y, z 坐标（z 通常为0，用于三维一致性）
    AINFO << "  朝向: " << vehicle_state.heading() << " rad";  // 航向角，以弧度为单位，从x轴正方向逆时针测量
    AINFO << "  线性速度: " << vehicle_speed << " m/s";        // 当前瞬时速度
    AINFO << "  角速度: " << angular_velocity << " rad/s";     // 转向速率
    AINFO << "  线性加速度: " << linear_acceleration << " m/s²"; // 当前加速度（正为加速，负为制动）
    AINFO << "  方向盘转角: " << steering_percentage << "%";    // 方向盘转角百分比，0%为正中
    AINFO << "  曲率: " << vehicle_state.kappa();              // 路径曲率，用于评估转向半径

    // ----------------------- 【2. 设置静止状态容忍度参数】 -----------------------
    // 速度容忍度：允许的最大速度（0表示必须完全静止）
    const double speed_tolerance = 0;      // 速度容忍度
    // 加速度容忍度：允许的最大加速度绝对值（考虑系统制动残余）
    const double accel_tolerance = 0.35;      // 加速度容忍度，考虑系统制动力
    // 方向盘角度容忍度：允许的最大方向盘偏移百分比（0.0表示必须完全回正）
    const double steering_tolerance = 0.0;    // 方向盘角度容忍度（0.5%）
    // 位置变化容忍度：连续帧间位置最大允许偏移量（单位：米）
    const double position_tolerance = 0.000;  // 位置变化容忍度（5mm）
    // 朝向变化容忍度：连续帧间航向最大允许变化（单位：弧度）
    const double heading_tolerance = 0.000;   // 朝向变化容忍度（约0.1度）

    // 从系统配置中获取“静止制动加速度”（车辆在停止时的典型制动加速度）
    const double standstill_acceleration = 0.3;  // 从配置文件获取

    // ----------------------- 【3. 静态变量：用于跨帧连续稳定检测】 -----------------------
    // 使用 static 结构体保存上一帧状态，实现跨帧状态记忆（关键！）
    // 仅在函数首次调用时初始化，后续帧复用
    static struct {
        int stable_count = 0;                 // 连续稳定帧计数器
        double last_x = 0.0;                  // 上一帧车辆x坐标
        double last_y = 0.0;                  // 上一帧车辆y坐标
        double last_heading = 0.0;            // 上一帧车辆航向角
        bool initialized = false;             // 是否已初始化基准
    } frame_check;

    // 所需连续稳定帧数：30帧 ≈ 1秒（假设30Hz频率）
    const int required_stable_frames = 30;  // 需要连续稳定的帧数（约1秒）

    // ----------------------- 【4. 当前帧静止状态初步判断】 -----------------------
    bool current_frame_static = true;  // 假设当前帧为静止状态
    std::string fail_reason = "";      // 记录失败原因（用于调试）

    // 检查1：车辆线速度和角速度是否在容忍范围内（必须为0）
    if (std::abs(vehicle_speed) > speed_tolerance || std::abs(angular_velocity) > speed_tolerance) {
        current_frame_static = false;  // 速度超标，非静止
        fail_reason = "速度未完全为零";
    }

    // 检查2：加速度是否在允许范围内（允许0或±0.3 m/s²，即系统制动残余）
    if (current_frame_static) {
        // 允许的加速度范围：0 或 ±standstill_acceleration（系统制动时的典型值）
        bool accel_acceptable = (std::abs(linear_acceleration) <= accel_tolerance)
                || (std::abs(linear_acceleration + standstill_acceleration) <= accel_tolerance)
                || (std::abs(linear_acceleration - standstill_acceleration) <= accel_tolerance);

        if (!accel_acceptable) {
            current_frame_static = false;  // 加速度异常，非静止
            fail_reason = "加速度异常";
            AINFO << "加速度检查失败：当前值=" << linear_acceleration << " m/s²，期望值=0或±" << standstill_acceleration
                  << " m/s²";  // 调试日志：输出当前值与期望值对比
        } else {
            AINFO << "加速度检查通过：当前值=" << linear_acceleration << " m/s²";  // 成功日志
        }
    }

    // 检查3：方向盘是否回正（必须为0%）
    if (current_frame_static && std::abs(steering_percentage) > steering_tolerance) {
        current_frame_static = false;  // 方向盘未回正
        AINFO << "方向盘未回正 - 当前转角: " << steering_percentage << "%, 容忍度: " << steering_tolerance << "%";  // 调试日志
    }

    // ----------------------- 【5. 连续帧位置与朝向稳定性检测】 -----------------------
    if (current_frame_static) {
        // 如果尚未初始化（第一次检测），记录当前帧为基准
        if (!frame_check.initialized) {
            frame_check.last_x = vehicle_state.x();           // 记录当前x坐标
            frame_check.last_y = vehicle_state.y();           // 记录当前y坐标
            frame_check.last_heading = vehicle_state.heading(); // 记录当前航向角
            frame_check.initialized = true;                   // 标记已初始化
            frame_check.stable_count = 1;                     // 第一帧稳定
            AINFO << "首次静止检查，记录基准位置，稳定帧数: 1/" << required_stable_frames;
            return false;  // 仅记录，未达到稳定帧数，不能判定完成
        }

        // 计算当前帧与上一帧的位置变化（欧氏距离）
        double position_change = std::sqrt(
                std::pow(vehicle_state.x() - frame_check.last_x, 2)
                + std::pow(vehicle_state.y() - frame_check.last_y, 2));

        // 计算当前帧与上一帧的朝向变化（弧度）
        double heading_change = std::abs(vehicle_state.heading() - frame_check.last_heading);

        // 处理航向角的周期性（避免跨越 ±π 时的跳变）
        // 例如：从 3.14 → -3.14 应为 0.02，而非 6.28
        if (heading_change > M_PI) {
            heading_change = 2 * M_PI - heading_change;
        }

        // 检查位置和朝向是否都在容忍范围内
        if (position_change <= position_tolerance && heading_change <= heading_tolerance) {
            // 状态稳定：稳定帧数 +1
            frame_check.stable_count++;
            AINFO << "车辆静止稳定中，稳定帧数: " << frame_check.stable_count << "/" << required_stable_frames;
            AINFO << "  位置变化: " << std::fixed << std::setprecision(4) << position_change
                  << "m, 朝向变化: " << heading_change << "rad";

            // 更新上一帧数据为当前帧，为下一次比较做准备
            frame_check.last_x = vehicle_state.x();
            frame_check.last_y = vehicle_state.y();
            frame_check.last_heading = vehicle_state.heading();

            // 若未达到所需稳定帧数，继续等待
            if (frame_check.stable_count < required_stable_frames) {
                return false;  // 未完成，返回 false
            }
        } else {
            // 位置或朝向发生显著变化，重置计数器
            frame_check.stable_count = 1;  // 重置为1（当前帧为新基准）
            frame_check.last_x = vehicle_state.x();
            frame_check.last_y = vehicle_state.y();
            frame_check.last_heading = vehicle_state.heading();
            AINFO << "车辆位置/朝向有变化，重置稳定计数器";
            AINFO << "  位置变化: " << std::fixed << std::setprecision(4) << position_change
                  << "m, 朝向变化: " << heading_change << "rad";
            return false;  // 未稳定，返回 false
        }
    } else {
        // 当前帧不满足静止条件（速度/加速度/方向盘异常），完全重置状态
        frame_check.stable_count = 0;      // 清零稳定帧计数
        frame_check.initialized = false;   // 清除初始化标记
        AINFO << "车辆状态不满足静止条件，重置稳定检查";
        return false;  // 未完成，返回 false
    }

    // ----------------------- 【6. 静止状态已满足：连续30帧稳定】 -----------------------
    AINFO << "车辆已连续 " << required_stable_frames << " 帧完全静止，状态稳定";

    // ----------------------- 【7. 检查车辆是否位于目标停车位内】 -----------------------
    // 若目标停车位ID为空，无法验证位置，直接失败
    if (scenario_context->target_parking_spot_id.empty()) {
        AWARN << "目标停车位ID为空，无法验证停车位置";
        frame_check.stable_count = 0;  // 重置状态
        frame_check.initialized = false;
        return false;
    }

    // 获取高精地图指针
    const hdmap::HDMap* hdmap = hdmap::HDMapUtil::BaseMapPtr();
    // 构造目标停车位ID对象（从字符串转换为 hdmap::Id）
    hdmap::Id parking_id;
    parking_id.set_id(scenario_context->target_parking_spot_id);
    // 从地图中查询该ID对应的停车位对象
    auto parking_spot = hdmap->GetParkingSpaceById(parking_id);

    // 若未找到该停车位，返回失败
    if (parking_spot == nullptr) {
        AWARN << "无法找到停车位: " << scenario_context->target_parking_spot_id;
        frame_check.stable_count = 0;  // 重置状态
        frame_check.initialized = false;
        return false;
    }

    // ----------------------- 【8. 定义车辆尺寸参数（硬编码）】 -----------------------
    // 注意：这些参数应从车辆配置文件加载，当前为典型值
    const double vehicle_length = 4.3;        // 车长 4米（从前轴到后轴）
    const double vehicle_width = 2.0;         // 车宽 2米
    const double front_edge_to_center = 4.2;  // 前边缘到车辆中心距离（近似为车长-后距）
    const double back_edge_to_center = 0.10;  // 后边缘到车辆中心距离（近似为后悬）
    const double left_edge_to_center = 1.0;   // 左边缘到中心距离（车宽一半）
    const double right_edge_to_center = 1.0;  // 右边缘到中心距离（车宽一半）

    // 获取车辆中心点（当前车辆位置）
    apollo::common::math::Vec2d vehicle_center(vehicle_state.x(), vehicle_state.y());
    double vehicle_heading = vehicle_state.heading();  // 航向角（弧度）

    // 构建车辆四个角点（相对于车辆中心的局部坐标，再旋转至全局坐标）
    std::vector<apollo::common::math::Vec2d> vehicle_corners;

    // 前左角：相对于中心，前+左
    apollo::common::math::Vec2d front_left(front_edge_to_center, left_edge_to_center);
    front_left = front_left.rotate(vehicle_heading);  // 旋转至全局坐标系
    vehicle_corners.push_back(vehicle_center + front_left);  // 加上中心点，得到全局坐标

    // 前右角：相对于中心，前+右
    apollo::common::math::Vec2d front_right(front_edge_to_center, -right_edge_to_center);
    front_right = front_right.rotate(vehicle_heading);
    vehicle_corners.push_back(vehicle_center + front_right);

    // 后右角：相对于中心，后+右
    apollo::common::math::Vec2d rear_right(-back_edge_to_center, -right_edge_to_center);
    rear_right = rear_right.rotate(vehicle_heading);
    vehicle_corners.push_back(vehicle_center + rear_right);

    // 后左角：相对于中心，后+左
    apollo::common::math::Vec2d rear_left(-back_edge_to_center, left_edge_to_center);
    rear_left = rear_left.rotate(vehicle_heading);
    vehicle_corners.push_back(vehicle_center + rear_left);

    // 获取目标停车位的多边形边界
    const auto& parking_polygon = parking_spot->polygon();
    // 设置边界容忍度：允许车辆角点在停车位边界外10cm内（工程容差）
    const double boundary_tolerance = 0.1;  // 10cm边界容忍度

    // 日志输出车辆位置与朝向，用于调试
    AINFO << "车辆位置: (" << vehicle_state.x() << ", " << vehicle_state.y() << ")";
    AINFO << "车辆朝向: " << vehicle_heading << " rad";
    AINFO << "车辆尺寸: " << vehicle_length << "m x " << vehicle_width << "m";

    // 输出停车位角点信息（调试用）
    const auto& parking_points = parking_polygon.points();
    AINFO << "停车位角点数量: " << parking_points.size();
    for (size_t i = 0; i < parking_points.size(); ++i) {
        AINFO << "停车位角点[" << i << "]: (" << std::fixed << std::setprecision(2) << parking_points[i].x() << ",
                " << parking_points[i].y() << ")";
    }

    // 统计超出停车位边界的角点数量
    int corners_outside_count = 0;

    // 对车辆每个角点进行检查
    for (size_t i = 0; i < vehicle_corners.size(); ++i) {
        const auto& corner = vehicle_corners[i];
        
        // 初步判断：角点是否在多边形内部
        bool corner_inside = parking_polygon.IsPointIn(corner);
        if (!corner_inside) {
            // 如果不在内部，计算该点到停车位边界的最小距离
            double min_distance_to_boundary = std::numeric_limits<double>::max();
            
            // 遍历停车位的每一条边（线段）
            for (size_t j = 0; j < parking_points.size(); ++j) {
                size_t next_j = (j + 1) % parking_points.size();  // 下一个点（循环）
                
                apollo::common::math::Vec2d line_start = parking_points[j];  // 线段起点
                apollo::common::math::Vec2d line_end = parking_points[next_j]; // 线段终点

                // 计算点到线段的距离（最短垂直距离）
                apollo::common::math::Vec2d line_vector = line_end - line_start;
                double line_length_squared = line_vector.LengthSquare();  // 线段长度平方

                double distance_to_segment = 0.0;

                // 若线段退化为点（极小长度），直接计算点到点距离
                if (line_length_squared < 1e-10) {
                    distance_to_segment = corner.DistanceTo(line_start);
                } else {
                    // 计算从线段起点到目标点的向量
                    apollo::common::math::Vec2d point_vector = corner - line_start;

                    // 计算投影参数 t = (point_vector · line_vector) / |line_vector|²
                    double t = point_vector.InnerProd(line_vector) / line_length_squared;

                    // 限制 t ∈ [0, 1]，确保投影点在线段上
                    t = std::max(0.0, std::min(1.0, t));

                    // 计算线段上最近点
                    apollo::common::math::Vec2d closest_point = line_start + line_vector * t;

                    // 计算目标点到最近点的距离
                    distance_to_segment = corner.DistanceTo(closest_point);
                }

                // 更新最小距离
                min_distance_to_boundary = std::min(min_distance_to_boundary, distance_to_segment);

                // 调试输出：每条边的距离计算结果
                AINFO << "  -> 到边界线段[" << j << "->" << next_j << "]的距离: " << std::fixed << std::setprecision(4)
                      << distance_to_segment << "m";
            }

            // 若最小距离在容忍范围内，认为角点“在边界内”
            if (min_distance_to_boundary <= boundary_tolerance) {
                corner_inside = true;  // 标记为有效
                AINFO << "车辆角点[" << i << "] (" << std::fixed << std::setprecision(2) << corner.x() << ", "
                      << corner.y() << ") "
                      << "在边界容忍范围内 (最小距离: " << std::fixed << std::setprecision(4)
                      << min_distance_to_boundary << "m)";
            } else {
                // 否则，计数为“超出”
                corners_outside_count++;
                AINFO << "车辆角点[" << i << "] (" << std::fixed << std::setprecision(2) << corner.x() << ", "
                      << corner.y() << ") "
                      << "超出停车位范围 (最小距离: " << std::fixed << std::setprecision(4) << min_distance_to_boundary
                      << "m)";
            }
        } else {
            // 角点在多边形内部，直接记录
            AINFO << "车辆角点[" << i << "] (" << std::fixed << std::setprecision(2) << corner.x() << ", " << corner.y()
                  << ") 在停车位内";
        }
    }

    // 设置允许超出的角点最大数量（当前为0，表示必须全部在内）
    const int max_allowed_outside_corners = 0;
    // 若超出数量超过允许值，则判定停车未完成
    if (corners_outside_count > max_allowed_outside_corners) {
        AINFO << "车辆有 " << corners_outside_count << " 个角点超出停车位，超过允许的 " << max_allowed_outside_corners
              << " 个，停车未完成";

        // 重置状态，为下一次停车检测准备
        frame_check.stable_count = 0;
        frame_check.initialized = false;
        return false;
    }

    // ----------------------- 【9. 停车完成：静止+位置均满足】 -----------------------
    AINFO << "停车完成检查通过：车辆已停稳且位于目标停车位内";
    AINFO << "重置frame_check状态，为下次停车检查做准备";

    // 重置静态变量，确保下次停车可重新检测
    frame_check.stable_count = 0;
    frame_check.last_x = 0.0;
    frame_check.last_y = 0.0;
    frame_check.last_heading = 0.0;
    frame_check.initialized = false;

    // 停车完成后清空轨迹（如有需要可调用 ClearPlanningTrajectory）
    // 注：此处未调用，但注释提示后续可扩展

    // 返回 true：停车完成
    return true;
}
```

```cpp
/**
 * @brief 判断当前场景是否可从其他场景（如巡航、跟车）切换至 BestParkingSpace 场景。
 *
 * 本函数用于决策是否应将控制权从当前场景（如 Planning 的巡航场景）转移到“最佳停车位场景”。
 * 转移条件包括：
 *   1. 开放空间规划未完成（否则无需泊车）
 *   2. 存在停车命令或路由终点附近有可用停车位
 *   3. 停车位未被占用
 *   4. 车辆距离目标停车位在可泊车范围内
 *   5. 目标停车位存在于当前参考线路径的Overlap中
 *
 * 本函数支持两种触发方式：
 *   - 显式停车命令（带停车位ID）
 *   - 自动搜索路由终点附近可用停车位（无命令时）
 *
 *
 * @param other_scenario 当前正在运行的其他场景（可能为巡航、跟车等），用于上下文判断
 * @param frame 当前帧全局状态，包含车辆状态、规划命令、地图、路径、障碍物等
 * @return bool true = 可以切换到 BestParkingSpace 场景；false = 不可切换
 */
bool BestParkingSpaceScenario::IsTransferable(const Scenario* const other_scenario, const Frame& frame) {
    
    // ----------------------- 【1. 检查开放空间规划是否已完成】 -----------------------
    // 如果开放空间规划（如平行泊车、垂直泊车路径规划）已经完成，则无需再进入本场景
    if (frame.open_space_info().openspace_planning_finish()) {
        AINFO << "开放空间规划已完成，不再进入BestParkingSpace场景";  // 防止重复进入泊车流程
        return false;
    }
    
    // 初始化目标停车位ID为空
    std::string target_parking_spot_id;
    
    // 获取配置中定义的“停车位起始范围”：车辆距离目标停车位多远开始触发泊车检测（单位：米）
    double parking_spot_range_to_start = context_.scenario_config.parking_spot_range_to_start();
    
    // 检查来自规划命令的停车指令是否存在
    auto parking_command = frame.local_view().planning_command->has_parking_command();
    // 检查停车指令中是否携带了具体的停车位ID
    auto parking_spot_id = frame.local_view().planning_command->parking_command().has_parking_spot_id();

    // 调试输出：停车命令与停车位ID是否存在
    AINFO<<"停车命令是否存在: " << parking_command;
    AINFO<<"停车位ID是否存在: " << parking_spot_id;

    // ----------------------- 【2. 检查其他场景或参考线是否有效】 -----------------------
    // 如果传入的其他场景为空（逻辑错误）或当前帧无参考线信息（路径未生成），则无法转移
    if (other_scenario == nullptr || frame.reference_line_info().empty()) {
        AINFO<<"其他场景或参考线信息为空，无法转移";  // 保护性判断，避免空指针
        return false;
    }

    // ----------------------- 【3. 检查车辆是否已在停车位内】 -----------------------
    // 若车辆当前已完全停在某个停车位内，则无需进入泊车场景（避免重复进入）
    if (IsVehicleAlreadyParked(frame)) {
        AINFO << "车辆已经在停车位内，无需进入泊车场景";  // 已完成泊车，无需干预
        return false;
    }

    // ----------------------- 【4. 处理显式停车命令（用户或上层指定停车位）】 -----------------------
    // 如果存在停车命令 且 命令中包含停车位ID
    if (parking_command && parking_spot_id) {
        // 获取用户指定的停车位ID
        target_parking_spot_id = frame.local_view().planning_command->parking_command().parking_spot_id();
        AINFO << "停车命令和停车位ID存在，目标停车位ID: " << target_parking_spot_id;
        
        // 获取高精地图指针，用于查询停车位对象
        const hdmap::HDMap* hdmap = hdmap::HDMapUtil::BaseMapPtr();
        // 构造目标停车位ID对象（从string转换为hdmap::Id）
        hdmap::Id id;
        id.set_id(target_parking_spot_id);
        // 从地图中查询该ID对应的停车位信息
        ParkingSpaceInfoConstPtr specified_parking_spot = hdmap->GetParkingSpaceById(id);
        
        // 如果该停车位存在，且被占用，则放弃指定，强制重新搜索
        if (specified_parking_spot != nullptr && IsParkingSpotOccupied(specified_parking_spot, frame)) {
            AINFO << "指定的停车位 " << target_parking_spot_id << " 已被占用，需要重新选择";
            target_parking_spot_id.clear(); // 清空ID，触发后续自动搜索流程
        }
    }

    // ----------------------- 【5. 处理无指定停车位的情况（自动搜索）】 -----------------------
    // 如果没有停车命令，或指定的停车位被占用（已被清空），则进入自动搜索模式
    if (!parking_command || target_parking_spot_id.empty()) {
        AINFO << "没有停车命令或指定停车位被占用，尝试获取路由结束点";
        
        // 获取路由规划的终点（WayPoint，即导航终点）
        const auto routing_end = frame.local_view().end_lane_way_point;
        
        // 如果路由终点为空（导航未提供终点），则无法进行搜索
        if (nullptr == routing_end) {
            AINFO << "路由结束点为空，无法获取目标停车位";  // 无目标，无法泊车
            return false;
        }
        
        // 创建一个ENU坐标点，用于地图查询
        common::PointENU end_postion;
        // 将路由终点的位姿（x, y）赋值给点
        end_postion.set_x(routing_end->pose().x());
        end_postion.set_y(routing_end->pose().y());
        AINFO << "路由结束点位置: " << end_postion.x() << ", " << end_postion.y();

        // 计算目标点在参考线上的SL坐标（S: 沿路径距离；L: 偏移距离）
        common::SLPoint dest_sl;
        const auto& reference_line_info = frame.reference_line_info().front();  // 获取主参考线
        const auto& reference_line = reference_line_info.reference_line();      // 获取参考线对象
        reference_line.XYToSL(routing_end->pose(), &dest_sl);                   // 将终点XY转换为SL

        // 获取车辆前边缘在参考线上的S坐标（车辆最前端在路径上的投影位置）
        const double adc_front_edge_s = reference_line_info.AdcSlBoundary().end_s();
        // 计算车辆前边缘到目标点的沿路径距离（单位：米）
        const double adc_distance_to_dest = dest_sl.s() - adc_front_edge_s;
        AINFO << "车辆前边缘S值: " << adc_front_edge_s;
        AINFO << "目标位置S值: " << dest_sl.s();
        AINFO << "车辆到目标位置的距离: " << adc_distance_to_dest;

        // 如果车辆距离终点超过配置的“起始范围”，则太远，不触发泊车
        if (adc_distance_to_dest > parking_spot_range_to_start) {
            AINFO << "车辆到目标位置的距离大于停车位起始范围，无法获取目标停车位";
            return false;
        }

        // 开始在路由终点附近查找停车位
        AINFO << "尝试在结束位置附近查找可用停车位";
        std::vector<apollo::hdmap::ParkingSpaceInfoConstPtr> parking_spaces;

        // 调用地图接口，在终点周围指定半径内搜索所有停车位
        // 返回0表示成功（非错误），非0表示地图查询失败
        if (hdmap_->GetParkingSpaces(end_postion, parking_spot_range_to_start, &parking_spaces) == 0
            && parking_spaces.size() > 0) {
            AINFO << "在结束位置附近找到停车位，总数量: " << parking_spaces.size();
            
            // 输出所有找到的停车位的详细信息（调试用）
            AINFO << "=== 所有找到的停车位详细信息 ===";
            for (size_t i = 0; i < parking_spaces.size(); ++i) {
                const auto& parking_space = parking_spaces[i];
                const auto& parking_info = parking_space->parking_space();
                
                AINFO << "停车位 [" << (i + 1) << "/" << parking_spaces.size() << "]";
                AINFO << "  - ID: " << parking_info.id().id();  // 停车位唯一标识
                
                const auto& polygon = parking_space->polygon();  // 获取多边形边界
                const auto& points = polygon.points();           // 获取所有角点
                AINFO << "  - 角点数量: " << points.size();     // 通常为4个，表示矩形
                
                // 输出每个角点的坐标（用于调试）
                for (size_t j = 0; j < points.size(); ++j) {
                    AINFO << "    角点[" << j << "]: ("  << std::fixed << std::setprecision(2) << points[j].x()
                                                                           << ", " << points[j].y() << ")";
                }
                
                // 若角点足够（≥4），计算几何中心和面积
                if (points.size() >= 4) {
                    // 计算中心点（四个角点的平均值）
                    Vec2d center_point = (points[0] + points[1] + points[2] + points[3]) / 4.0;
                    AINFO << "  - 中心点: (" << center_point.x() << ", " << center_point.y() << ")";
                    AINFO << "  - 面积: " << polygon.area() << " 平方米";  // 停车位面积
                    
                    // 计算当前车辆到该停车位中心的距离
                    Vec2d vehicle_pos(frame.vehicle_state().x(), frame.vehicle_state().y());
                    double distance = vehicle_pos.DistanceTo(center_point);
                    AINFO << "  - 距离车辆: " << distance << " 米";
                }
                
                // 如果停车位有航向角（朝向），也输出
                if (parking_info.has_heading()) {
                    AINFO << "  - 航向角: " << parking_info.heading() << " 弧度";
                }
                
                AINFO << "  ---";  // 分隔线，便于阅读
            }
            AINFO << "=== 停车位信息输出完毕 ===";
            
            // 筛选所有未被占用的停车位
            std::vector<ParkingSpaceInfoConstPtr> available_spots;
            for (auto parking_space : parking_spaces) {
                AINFO << "检查停车位ID: " << parking_space->parking_space().id().id();
                // 检查该停车位是否被障碍物占用
                if (!IsParkingSpotOccupied(parking_space, frame)) {
                    available_spots.push_back(parking_space);  // 加入可用列表
                    AINFO << "停车位 " << parking_space->parking_space().id().id() << " 可用";
                } else {
                    AINFO << "停车位 " << parking_space->parking_space().id().id() << " 被占用，跳过";
                }
            }
            
            // 如果没有找到任何可用停车位，返回失败
            if (available_spots.empty()) {
                AINFO << "附近没有可用的停车位";
                return false;
            }
            
            // 从可用停车位中选择最佳的一个（根据距离、朝向等）
            target_parking_spot_id = SelectBestAvailableParkingSpot(available_spots, frame);
            
        } else {
            // 地图查询失败，或未找到任何停车位
            AINFO << "在结束位置附近未找到任何停车位";
            return false;
        }
    }

    // ----------------------- 【6. 检查最终目标停车位ID是否有效】 -----------------------
    // 如果经过所有逻辑后，目标停车位ID仍为空，说明未找到有效目标
    if (target_parking_spot_id.empty()) {
        AINFO << "目标停车位ID为空，无法获取目标停车位";
        return false;
    }

    // 输出最终选定的目标停车位ID（用于调试）
    AINFO<<"最终选择的目标停车位ID: " << target_parking_spot_id;

    // 获取当前参考线的路径信息（用于Overlap检测）
    const auto& nearby_path = frame.reference_line_info().front().reference_line().map_path();
    PathOverlap parking_space_overlap;  // 用于存储目标停车位在路径上的Overlap信息
    const auto& vehicle_state = frame.vehicle_state();

    // 输出车辆状态（调试用）
    AINFO << "车辆状态: " << vehicle_state.DebugString();

    // 在路径上搜索目标停车位的Overlap（即：该停车位是否在车辆前方路径上）
    if (!SearchTargetParkingSpotOnPath(nearby_path, target_parking_spot_id, &parking_space_overlap)) {
        AINFO << "在附近路径上未找到目标停车位，无法获取目标停车位";  // 停车位不在路径上，无法泊车
        return false;
    }

    // 检查车辆到目标停车位的距离是否在允许范围内（避免过早或过晚触发）
    if (!CheckDistanceToParkingSpot(
                frame, vehicle_state, nearby_path, parking_spot_range_to_start, parking_space_overlap)) {
        AINFO << "车辆到停车位的距离大于预定义距离，无法获取目标停车位";  // 距离过远，不触发
        return false;
    }

    // ----------------------- 【7. 设置场景上下文并返回成功】 -----------------------
    // 将选定的目标停车位ID存入场景上下文，供后续泊车模块使用
    context_.target_parking_spot_id = target_parking_spot_id;
    
    // 返回true：满足所有转移条件，可切换至BestParkingSpace场景
    return true;
}
```

- 函数`StageBestParking::Process`

```cpp
/**
 * @brief 执行“最佳停车位场景”中的泊车任务主流程。
 *
 * 本函数是 StageBestParking 的核心处理函数，负责：
 *   1. 初始化开放空间规划上下文（设置目标停车位ID）
 *   2. 检查车辆是否已成功停稳（完成泊车）
 *   3. 若未完成，则调用开放空间规划模块执行泊车轨迹生成与跟踪
 *   4. 返回当前阶段状态（RUNNING 或 ERROR 或 FINISHED）
 *
 *
 * @param planning_init_point 上游规划模块传入的初始轨迹点（本阶段忽略）
 * @param frame 当前帧的全局状态，包含车辆状态、路径、障碍物、目标停车位等
 * @return StageResult 当前阶段执行结果（RUNNING / ERROR / FINISHED）
 */
StageResult StageBestParking::Process(const common::TrajectoryPoint& planning_init_point, Frame* frame) {

    // 调试日志：记录任务执行完毕
    AINFO<<"StageBestParking::Process 执行任务结束";
    
    // ----------------------- 【3. 检查任务执行是否出错】 -----------------------

    // 若无错误，且未完成泊车，则阶段继续运行，等待下一帧继续执行
```

```cpp
 * 最终输出的 roi_parking_boundary 是一个二维向量，每一行代表一条边界线段（起点和终点），构成一个闭合区域。
```

**问题解决方法**：

| 问题现象                       | 解决方案                                                         |
| ------------------------------ | ---------------------------------------------------------------- |
| 90s超时                        | 收紧`astar_max_search_time`、降低`ipopt_max_iter`、适度提高速度上限 |
| 反复切段或抖动                 | 提高`vehicle_box_iou_threshold_to_midpoint`、略增`heading_search_range` |
| 靠边压线或入位空间不足         | 增大`perception_obstacle_buffer`与`parking_depth_buffer`           |
| 误判空车位为占用/占用未过滤   | 检查障碍物速度阈值/多边形重叠阈值，核对Prediction/Frame数据一致性  |
| 停车完成判定不稳定（抖动）     | 提高连续稳定帧数、收紧速度/加速度/方向盘容忍度                    |

**最终验证**：

- 可用车位搜索：指定范围内能稳定选择最近可用车位，日志打印ID及距离。
- ROI扩展：扩展点坐标与面积打印正确，无障碍穿越；ROI XY 边界包含车辆位置。
- 轨迹生成：Hybrid A* 暖启动与优化时长在可控范围内，全程<90s。
- 停车完成：连续稳定帧满足，四角点在多边形内（允许小容忍）；无压线即判定完成。
